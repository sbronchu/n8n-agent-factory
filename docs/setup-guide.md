# Guia de Configuracion\n\n## 1. Estructura del Repositorio\n\nEste repositorio contiene:\n\n- **agents/**: 19 perfiles de agentes especializados\n- **tools/**: Definiciones de herramientas (Telegram, Discord, WhatsApp)\n- **models/**: Configuracion de LLMs y reglas de routing\n\n## 2. Como Crear un Nuevo Agente para un Cliente\n\n### Paso 1: Seleccionar un Agente Base\n\n1. Ve a la carpeta **agents/**\n2. Elige uno de los 19 agentes disponibles\n3. Copia la carpeta del agente y renombrala con el ID del cliente\n\n### Paso 2: Personalizar el Agente\n\nEdita los 3 archivos del agente:\n\n#### a) **agent.json**\n- Cambia el **id** por algo unico (ej: "sales-cliente-123")\n- Actualiza el **name**\n- Anade las **tools** que necesite el cliente\n- Actualiza las rutas de los archivos\n\n#### b) **AGENTS.md** (Personalidad)\n- Personaliza el **system_prompt**\n- Ajusta el **tone** de la personalidad\n- Anade **rules** especificos del cliente\n- Incluye **examples** relevantes\n\n#### c) **USERS.md** (Perfil del Cliente)\n- Cambia **client_id** y **client_name**\n- Actualiza **industry** y **team_size**\n- Anade **custom_instructions**\n- Actualiza **tech_stack**\n\n### Paso 3: Configurar el Workflow en n8n\n\n1. Clona el workflow generico (disponible en templates/generic-agent.json)\n2. Configura el parametro **AGENT_ID** con el ID del agente\n3. Anade las **tools** que necesites en el nodo AI Agent\n4. Configura las **credentials** de las herramientas\n5. Activa el workflow\n\n## 3. Configuracion de LLMs\n\n### Modelo Simple (Local - Ollama)\n- Usado para: Chat simple sin herramientas\n- URL: http://172.22.0.6:11434\n- Modelos: llama3.1:8b, mistral:7b\n\n### Modelo Complex (Cloud - OpenAI)\n- Usado para: Tareas con herramientas externas\n- Modelos: gpt-4o-mini, gpt-4o\n- Requiere: API key de OpenAI\n\n## 4. Configuracion de Memoria\n\nEl sistema usa PostgreSQL para memoria:\n\n- **Tabla conversations**: Historial de conversaciones (short-term)\n- **Tabla session_summaries**: Resumen de sesiones (long-term)\n- **Tabla user_profiles**: Cache de perfiles de usuario\n\n## 5. Como Funciona el Routing\n\nEl workflow decide automaticamente el modelo a usar:\n\n1. Si el agente tiene **tools** configuradas → Usa modelo **cloud**\n2. Si el mensaje es corto y sin tools → Usa modelo **local**\n3. Si necesita acceso a base de datos → Usa modelo **cloud**\n4. Por defecto → Usa modelo **local**\n\n## 6. Ejemplo Completo\n\n### Cliente: Tienda Online de Ropa\n\n1. Agente base: **sales**\n2. Copiar:  → \n3. Personalizar:\n   - **agent.json**: id="sales-tienda-xyz", tools=["telegram", "whatsapp"]\n   - **AGENTS.md**: system_prompt="Eres un vendedor de ropa online..."\n   - **USERS.md**: client_name="Tienda XYZ", industry="retail", team_size=5\n4. Workflow en n8n:\n   - AGENT_ID = "sales-tienda-xyz"\n   - Anadir nodes Telegram y WhatsApp\n   - Configurar credenciales\n   - Activar\n\n## 7. Troubleshooting\n\n### El agente no responde\n- Verificar que el workflow esta activo\n- Verificar que el AGENT_ID es correcto\n- Revisar logs de n8n\n\n### Error al cargar AGENTS.md\n- Verificar que la URL en agent.json es correcta\n- Verificar que el archivo existe en GitHub\n- Verificar que el repo es publico\n\n### Modelo local no funciona\n- Verificar que Ollama esta corriendo en http://172.22.0.6:11434\n- Verificar que el modelo esta descargado (llama3.1:8b)\n\n## 8. Soporte\n\nPara dudas o problemas, revisa el repo o contacta al administrador.\n
